This browser can't reach USB

iPhone and iPad block USB in every browser, so installs here go over WiFi. A brand-new board needs one USB install first, from an Android phone (Chrome) or a computer with Chrome or Edge. Send them this page:

Which board?

Plug the board into this phone with a USB-C data cable.

If Flash can't find the board: hold BOOT, tap RESET, release BOOT, then try again. After flashing that way, tap RESET to start the new firmware.
